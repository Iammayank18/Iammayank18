## About

I build production web and mobile products. Mostly React and React Native on the frontend, Node on the backend, TypeScript everywhere.

Day to day I work on a real estate SaaS used by 30,000+ agents across the US and Canada. Most of my time there goes into performance and into keeping large data views fast when the data stops being small.

Outside of that I ship my own things. VocalHyre is a live AI mock interview platform I built solo. Echo is a desktop transcription app. mimi.js is a Node framework I published. I also write on Medium about how React actually works underneath, mostly the parts people get wrong.

## What I Have Shipped

**Reax** · real estate SaaS, 30,000+ agents across the US and Canada
Built React and React Native features across web and mobile. Rendered 100k+ records on a single screen using virtualization and pagination so it stayed usable. Cut one CRM's load time from around 5 seconds to under 2 by profiling bundle size and state hydration, then fixing it with code splitting and lazy loading. Also built a shared TypeScript component library used by both the web and mobile teams, and a digital signature platform brokers use daily.

**WayVerb** · school management SaaS, founded and shipped solo
Every layer, alone. React and React Native clients on a single REST API, NestJS and MongoDB behind it, JWT with refresh token rotation and role based access for admins, teachers, parents and students. Ran the infra myself on AWS with Docker and GitHub Actions. Talked to schools directly and changed the data model twice because of what they said.

**Mindnerves** · real time job tracking platform
Shipped React Native features on a production app with thousands of active users. The app was refetching on every screen transition even when nothing had changed, so I moved data fetching to TanStack Query with caching and request deduplication and cut redundant calls by about 25%.
